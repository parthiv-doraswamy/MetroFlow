How MetroFlow works

The project started as a C++ graph implementation and grew into a web application. Dijkstra handles weighted route searches, BFS handles nearby-station discovery, and Node.js exposes the C++ engine through a small REST API. Repeated route searches are kept in a small in-memory cache.
